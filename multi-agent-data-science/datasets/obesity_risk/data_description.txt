3. Overview

Welcome to the 2024 Kaggle Playground Series.

Kaggle plans to continue the spirit of previous playground competitions by providing interesting and approachable datasets for the community to practice machine learning skills.

The Playground Series usually provides one competition each month.


============================================================
4. Goal
============================================================

The goal of this competition is to use different factors to predict obesity risk in individuals.

This obesity risk is related to cardiovascular disease.

Target Variable:
NObeyesdad

Task Type:
Multi-class classification


============================================================
5. Evaluation

6. Submission File Format
============================================================

For each id row in the test set, participants must predict the class value of the target variable NObeyesdad.

The submission file must contain a header and follow this format:

id,NObeyesdad
20758,Normal_Weight
20759,Normal_Weight
20760,Normal_Weight
etc.

8. Synthetically Generated Datasets
============================================================

The Playground competitions use synthetic data.

Using synthetic data helps Kaggle balance two goals:
- providing real-world-like data with named features
- keeping test labels private

The datasets are generated from real-world data, but they are not exactly the same as the original datasets.

The goal is to create interesting datasets with fewer synthetic artifacts.

Kaggle also encourages feedback from participants to improve future competition datasets.

14. Data
============================================================

The dataset for this competition, including both train and test files, was generated from a deep learning model.

The deep learning model was trained on the Obesity or CVD Risk dataset.

Original Dataset:
https://www.kaggle.com/datasets/aravindpcoder/obesity-or-cvd-risk-classifyregressorcluster

The feature distributions are close to the original dataset, but they are not exactly the same.

Participants are allowed to use the original dataset as part of this competition.

The original dataset can be used to:
- explore differences between the synthetic dataset and the original dataset
- check whether adding the original data improves model performance
