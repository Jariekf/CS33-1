Dataset: Ecommerce Product Text Dataset

Overview:
This dataset is a product-text classification dataset. Each row contains a product category label and a long free-text product description. The data appears suitable for category prediction from product listing text, product search indexing, text embedding, or other e-commerce NLP tasks.

Local file:
- ecommerce_dataset.csv: 50,425 rows, 2 columns when read without a header

Important file-format note:
The CSV file does not contain a header row. If it is loaded with the default CSV behavior, the first product record may be incorrectly treated as column names. It should be read with header=None and assigned explicit column names.

Recommended column names:
- category
- description

Prediction task:
- Task type: Multiclass text classification
- Input text: description
- Label column: category

General data characteristics:
- 4 category labels are present in the local data:
  - Household
  - Books
  - Electronics
  - Clothing & Accessories
- Category counts in the local data:
  - Household: 19,313
  - Books: 11,820
  - Electronics: 10,621
  - Clothing & Accessories: 8,671
- One row has a missing description value.
- Product descriptions are typically long-form listing text. In the local data, description length has a median of about 487 characters.

Column descriptions:

category:
Product category label. This is the classification target.

description:
Free-text product title and description. The text often includes brand names, product attributes, dimensions, colors, marketing copy, and purchase-oriented language.

Suggested modeling notes:
- This is primarily an NLP dataset, so text cleaning, tokenization, or embedding-based methods are appropriate.
- Because the file has no header row, data-loading code should explicitly set the schema.
- The long descriptions may contain noise such as repeated promotional text, formatting artifacts, and inconsistent capitalization.
